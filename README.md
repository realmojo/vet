# vet.keywordegg.com

동물병원 진료비를 **시군구별로** 보여주고, 강아지·고양이가 먹어도 되는 음식을
함께 담은 사이트. medifee·yoyang·sanhu 와 같은 스택(Next.js + Supabase +
Cloudflare Workers)과 같은 UI 스킨을 쓴다.

---

## 두 축을 한 사이트에 담은 이유

- **진료비**는 값이 시군구마다 실제로 다르고 검색 의도가 선명하다. 다만
  35항목 × 201지역이라 페이지 수가 크지 않다.
- **음식 사전**은 66건뿐이지만 "강아지가 초콜릿 먹었어요" 같은 급한 검색을
  받는다. 그 사람이 다음에 찾는 것이 "우리 동네 동물병원 얼마"다.

두 축을 서로 링크로 잇는 것이 이 사이트의 설계다. 음식 상세에서 진료비로,
지역 상세에서 음식으로 넘긴다.

## URL 구조

경로가 한 단계다. `app/[slug]/page.tsx` 하나가 여덟 종류의 화면을 나눠 맡는다.

| 경로 | 화면 | 정의 위치 |
|---|---|---|
| `/` | 홈 | `app/page.tsx` |
| `/진료비` | 항목 허브 | `ITEM_HUB_SLUG` (`lib/fee-items.ts`) |
| `/초진-진찰료-5kg` | 항목 상세 | `ITEMS` (`lib/fee-items.ts`) |
| `/지역` | 지역 허브 | `REGION_HUB_SLUG` (`lib/regions.ts`) |
| `/서울` | 시도 상세 | `SIDOS` (`lib/regions.ts`) |
| `/서울-강남구` | 시군구 상세 | `vet_regions.region_slug` |
| `/음식` | 음식 허브 | `FOOD_HUB_SLUG` (`lib/foods.ts`) |
| `/강아지` `/고양이` | 동물별 음식 목록 | `ANIMALS` (`lib/foods.ts`) |
| `/강아지-초콜릿` | 음식 상세 | `vet_foods` |
| `/about` `/contact` `/privacy` `/terms` | 안내 페이지 | 각 디렉터리 |

슬러그는 한글을 쓴다. **찾는 순서가 중요하다** — 고정 슬러그(허브·동물·시도) →
코드에 박힌 항목 → DB 에서 오는 음식·지역 순이다. 뒤집으면 DB 값이 고정 화면을
가린다.

슬러그 공간이 겹치지 않는 것은 확인해 뒀다. 음식은 `강아지-`·`고양이-` 로,
지역은 시도 짧은 이름(`서울-`, `경기-` …)으로 시작하고 항목 슬러그에는 그
접두사가 없다.

## 데이터 — 진료비

농림축산식품부 **동물병원 진료비 조사·공개 시스템** <https://animalclinicfee.or.kr>

2023년부터 동물병원은 주요 진료비 **20종**을 게시할 의무가 있고, 정부가 그것을
해마다 조사해 **시군구 단위**로 최저·최고·평균·중간값을 공개한다.
20종을 개체·체중별로 펼치면 35조합이 된다.

```bash
npm run probe:fees      # 조합 하나만 받아 응답 모양 확인
npm run import:fees     # 전량 수집 + 적재 (595 요청, 약 5분)
npm run import:fees -- --dry-run
npm run load:fees       # 이미 받아 둔 data/raw/fees.json 만 적재
```

**공공데이터포털에는 전국 진료비 데이터셋이 없다.** 포털에 있는 것은 동물병원
인허가 목록(15045050)뿐이다. 그래서 위 시스템의 조회 화면이 쓰는 내부 JSON
(`POST /info/searchPrice.json`) 을 읽는다.

> 공개 API 가 아니므로 **규격이 예고 없이 바뀔 수 있다.** 적재 스크립트가 응답이
> 배열인지, 시도 코드를 아는지 검증하고 아니면 멈춘다. 조사가 연 1회라 자주
> 돌릴 이유도 없어 요청 간격을 400ms 로 둔다.

요청 수는 **시도 17 × 항목 35 = 595**. 결과는 5,784행 / 시군구 201곳.
코드 목록은 `scripts/fee-codes.mjs` 에 있고, 조회 화면의 `<select>` 와 라디오
버튼 `data-*` 속성에서 뽑았다. 항목이 바뀌면 그 화면에서 다시 뽑는다.

### 지역 비교는 금액이 아니라 가격지수로 한다

**이게 이 사이트에서 가장 중요한 판단이다.**

처음에는 "그 지역 항목 중간값들의 중간값"으로 지역을 줄 세웠는데, 충남 서천군이
7,500원으로 전국 최저가 나왔다. 싼 게 아니었다 — **값이 있는 항목이 15개뿐**이라
MRI·CT 같은 비싼 항목이 통째로 빠진 것이다. 군 단위는 그런 장비를 갖춘 병원이
없어서 항목이 8~19개만 잡힌다. 커버리지를 가격으로 착각하게 만드는 지표였다.

그래서 **가격지수**로 바꿨다. 그 지역이 가진 항목마다 `지역 중간값 ÷ 전국
중간값` 을 구하고, 그 비율들의 중간값을 100 기준으로 적는다. 어떤 항목을 가졌든
각 항목을 전국과 1:1 로 견주므로 구성이 달라도 비교가 성립한다.

바꾸고 나니 순위가 말이 된다 — 서울 강남구 116, 대구 수성구 112, 전남 화순군 70.

항목이 20개 미만인 지역은 화면에서 **"표본 얇음"** 을 붙이고 순위 계산에서 뺀다.

### 최저·최고가 아니라 중간값을 앞세운다

집계 통계라 한 항목에 네 값(최저·최고·평균·중간)만 있다. 최저와 최고는 **한
곳만 있어도 잡히는 값**이다. 강남구 초진 진찰료가 최저 5,000 · 중간 11,000 ·
평균 15,078 · 최고 50,000 인데, 평균이 최고값 하나에 끌려 올라가 있다.

## 데이터 — 음식 사전

petpawpaw.net 에서 옮겨 왔다. 66건(개 42 · 고양이 24).

```bash
npm run import:foods              # pawpaw_foods → vet_foods
node scripts/import-foods.mjs --dry-run
```

같은 Supabase 프로젝트라 네트워크를 건너지 않는다. **원본(`pawpaw_foods`)은
건드리지 않는다.** `(animal, slug)` 가 고유키라 다시 돌려도 중복되지 않는다.

신호등(안전·주의·위험)은 **색만으로 구분하지 않는다.** 색약인 사람에게 초록과
빨강은 잘 갈라지지 않으므로 이모지와 글자를 항상 함께 붙인다.

## 테이블

| 테이블 | 내용 |
|---|---|
| `vet_fees` | 진료비 원본 5,784행 (항목 × 시군구) |
| `vet_regions` | 시군구 집계 201행. 가격지수·초진·종합백신 |
| `vet_items` | 항목 집계 35행. 전국 중간값·최저/최고 지역 |
| `vet_foods` | 음식 사전 66건 |

집계 두 개는 매 요청 계산하지 않고 `refresh_vet_aggregates()` 로 적재 후 한 번에
다시 만든다. 적재 스크립트가 마지막에 호출한다.

> 이 Supabase 프로젝트는 `pg_safeupdate` 가 켜져 있어 **WHERE 없는 DELETE 가
> 막힌다.** 집계 함수 안에서 `delete ... where true` 를 쓰는 이유다.

## 시작하기

```bash
# 1) Supabase SQL 편집기에서 마이그레이션 실행
#    supabase/migrations/001_create_vet_tables.sql
#    supabase/migrations/002_vet_regions_price_index.sql

# 2) .env.example 을 .env.local 로 복사해 채운다
#    Supabase 는 keywordegg 계열과 같은 프로젝트를 쓴다

# 3) 데이터 적재
npm run import:fees
npm run import:foods

# 4) 개발 서버
npm run dev
```

**진료비 수집에는 API 키가 필요 없다.** 원본이 공공데이터포털이 아니라
농림축산식품부 진료비 공개 시스템이고 인증이 걸려 있지 않다.

## 배포

```bash
npm run cf:deploy
```

배포 후 Cloudflare 대시보드에서 커스텀 도메인 `vet.keywordegg.com` 을 연결한다.

### 애드센스

퍼블리셔 ID 는 keywordegg 계열과 같은 계정이라 새로 승인받을 필요가 없다.
**슬롯은 이 사이트용으로 따로 만들어야 한다** — 다른 사이트 슬롯을 그대로 쓰면
리포트에서 수익이 섞인다. `lib/ads.ts` 의 `AD_SLOTS` 가 지금 빈 문자열이라
광고 자리가 아예 그려지지 않는다. 단위를 만든 뒤 채우면 그때부터 노출된다.
